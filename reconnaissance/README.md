# Network Reconnaissance

This lab explores network reconnaissance and traffic analysis within an isolated virtual environment.

Nmap was used for active reconnaissance to discover hosts, identify exposed ports and services, perform service and OS detection, and evaluate network attack surfaces. Wireshark was used to capture and analyze network traffic, examine protocol behavior, compare passive and active reconnaissance, and observe the security differences between encrypted and unencrypted protocols.
